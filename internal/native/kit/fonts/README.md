# Fonts

The kit's fonts, registered with `ui.RegisterFont` (`kit.RegisterFonts`).
MyGo reads TrueType and OpenType only, so these are the variable TTFs from
the upstream releases, not the WOFF2 files the frontend gets from
`@fontsource-variable`. Both are under the SIL Open Font License 1.1
(`OFL-*.txt`).
