## Turn 1

**User:** What is a moving average?

**Agent:** A moving average is a technical analysis tool that smooths out price data by creating a constantly updated average price. It helps filter out "noise" (short-term fluctuations) to reveal the underlying trend of an asset over time.

There are two common types:
*   **Simple Moving Average (SMA):** The arithmetic mean of a set of prices over a specific period (e.g., the last 20 days).
*   **Exponential Moving Average (EMA):** Similar to the SMA, but it gives more weight to recent prices, making it more responsive to new information.
